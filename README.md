# Juego 2D Pixel Adventure

## Descripción y Objetivo
Este proyecto es un juego de plataformas 2D desarrollado en Unity utilizando una plantilla Universal 2D. 

El objetivo del juego es manejar al personaje a través de 3 niveles distintos, eliminando enemigos, recogiendo objetos y el trofeo de cada nivel hasta superar el último nivel para volver al menú.

---

## Controles
* **Moverse a la izquierda / derecha:** Teclas `A` / `D` (o Flecha Izquierda / Flecha Derecha)
* **Saltar:** Tecla `Espacio`
* **Lanzar sierra:** Tecla `C`
* **Golpear:** Tecla `X`

---

## Mecánicas Principales
- **Vidas:** 
El personaje cuenta con 3 puntos de vida que disminuyen al recibir daño. El nivel se reinicia si el personaje pierde las 3 vidas o cae al vacio
- **Frutas:** Son objetos recogibles, hay manzanas, bananas y cerezas repartidas en el mapa. Al cogerlas se recarga munición
- **Enemigos:** Tienen un tramo predefinido y si los tocas pierdes una vida. Requieren al menos 2 impactos para ser derrotados.
- **Niveles:** Hay tres niveles con distintos diseños pero mismas mecánicas

---

## Instrucciones para abrir el proyecto
1. Descarga o clona este repositorio en tu equipo.
2. Abre Unity Hub 6.
3. Haz clic en Add (Añadir) y selecciona la carpeta raíz del proyecto.
4. Abre la escena inicial ubicada en `Assets/Scenes/MainMenu.unity` y pulsa Play para iniciar el juego desde el menú.
